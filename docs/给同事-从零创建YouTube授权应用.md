# 从零创建我们自己的 YouTube 授权应用（给同事·详细版）

你好，我们要新建一个**归我们自己的** Google 授权应用（整个系统用这**一个**就够，以后所有 YouTube 账号都通过它授权）。
你按下面做，最后把 **客户端 ID + 客户端密钥** 两样东西发给我即可。全程约 15 分钟。

> 说明：**不是每个 YouTube 账号建一个项目**。是**整个系统建一个应用**，它能给很多个 YouTube 账号授权。这份文档就是建这一个应用。

---

## 准备：用哪个 Google 账号来建

- 建议用一个**你们长期持有、能管住的 Google 账号**来创建这个项目（不一定是发视频那个账号，就当“管理员账号”）。
- 全程在 **https://console.cloud.google.com** 里操作。第一次进可能要求同意条款、选国家，照提示点即可。

---

# 第 1 大步：新建项目

1. 打开 **https://console.cloud.google.com** ，用管理员账号登录。
2. 点页面**最顶部**的**项目下拉框**（Google Cloud 标志右边，可能显示“选择项目 / Select a project”）。
3. 弹窗右上角点 **新建项目（NEW PROJECT）**。
4. 项目名称填：`ihouse-youtube-publish`（随意，能认出来就行），位置/组织默认即可。
5. 点 **创建（CREATE）**，等几秒创建完成。
6. 创建完，**再点一次顶部项目下拉框，把当前项目切换成刚建的这个**（很重要，后面都在这个项目里操作）。

---

# 第 2 大步：开启 YouTube Data API

1. 左上角 **☰ 菜单 → API 和服务（APIs & Services）→ 库（Library）**。
2. 搜索框输入 `YouTube Data API v3`，点进搜索结果里的 **YouTube Data API v3**。
3. 点 **启用（ENABLE）**，等它开启完成。✅

---

# 第 3 大步：配置「OAuth 同意屏幕」（应用的基本信息）

> 界面有新旧两版，下面两版都写了，你看到哪版按哪版做。

### 情况 A：新版界面（左侧有「Google Auth Platform」）
1. **☰ 菜单 → API 和服务 → OAuth 同意屏幕**（或左侧「Google Auth Platform → 概览 / Overview」）。
2. 如果提示还没配置，点 **开始配置 / Get started**。
3. 按表单填：
   - **应用名称（App name）**：`iHouse OpenNews`（随意，用户授权时会看到这个名字）
   - **用户支持电子邮件（User support email）**：选你的管理员邮箱
   - **目标对象（Audience）**：选 **外部（External）**
   - **开发者联系信息（Developer contact）**：填你的邮箱
4. 一路 **保存并继续 / Continue**，直到完成。

### 情况 B：旧版界面
1. **☰ 菜单 → API 和服务 → OAuth 同意屏幕**。
2. **User Type** 选 **外部（External）** → 创建（CREATE）。
3. 填 **应用名称**、**用户支持邮箱**、**开发者联系邮箱** → 保存并继续。
4. **范围（Scopes）** 这一步：先不用加，直接 **保存并继续**（真正的权限在我们系统里已经指定好了）。
5. **测试用户（Test users）** 这一步：先跳过或随便，后面第 6 大步再加 → 保存并继续。
6. 看一眼摘要 → 返回信息中心。

---

# 第 4 大步：创建「OAuth 客户端 ID」⭐ 这一步产出我要的东西

1. **☰ 菜单 → API 和服务 → 凭据（Credentials）**。
2. 顶部点 **+ 创建凭据（+ CREATE CREDENTIALS）→ OAuth 客户端 ID（OAuth client ID）**。
3. **应用类型（Application type）** 选 **Web 应用（Web application）**。
4. **名称（Name）** 填：`ihouse-web`（随意）。
5. 找到 **已获授权的重定向 URI（Authorized redirect URIs）** → 点 **+ 添加 URI（+ ADD URI）** → 原样粘贴这一行：
   ```
   https://aiagent.office.ihousejapan.cn/api/youtube/oauth/callback
   ```
   ⚠️ 必须一字不差，包括 `https://` 和结尾的 `/callback`，不要多空格。
6. 点 **创建（CREATE）**。
7. 弹出一个窗口，显示 **客户端 ID（Client ID）** 和 **客户端密钥（Client secret）** —— **这两样就是我要的**：
   - 点复制按钮，或点「下载 JSON」把它保存下来。
   - **发给我**（见第 7 大步）。

---

# 第 5 大步：把应用设为「已发布 / 正式」⭐ 很重要，否则授权一周就失效

> 原因：应用停在「测试」状态时，授权凭据**约 7 天就过期**，会导致过一阵子自动发布突然失效。设为「已发布」就不会过期。

1. 回到 **OAuth 同意屏幕**（或新版「Google Auth Platform → 目标对象 / Audience」）。
2. 找到 **发布状态（Publishing status）**，当前多半是「测试中 / Testing」。
3. 点 **发布应用（PUBLISH APP）**，弹窗确认 **确认 / Confirm**。
4. 状态变成「正式版 / In production」即可。✅
   - 期间如果提示要「验证 / verification」——**不用去做验证**。发布后我授权时会看到一个「未经验证的应用」提示页，点「高级 / Advanced → 继续前往」即可通过，不影响使用。

---

# 第 6 大步（可选）：如果你不发布、想继续用「测试」状态

如果第 5 步你没发布、保持「测试中」，那就必须把每个要授权的 YouTube 账号邮箱加进测试用户：
1. OAuth 同意屏幕 / 目标对象(Audience) → **测试用户（Test users）→ + 添加用户**。
2. 填入 YouTube 账号邮箱 → 保存。
> ⚠️ 但测试状态凭据约 7 天过期，长期自动发布不推荐。**建议还是走第 5 大步「发布应用」**。

---

# 第 7 大步：把结果交给我

发我这几样：

1. **客户端 ID（Client ID）**：`____________________.apps.googleusercontent.com`
2. **客户端密钥（Client secret）**：`____________________`
3. 应用**发布状态**：已发布 / 还是测试中（若测试中，把要授权的账号邮箱也发我）
4. 你准备好的 **YouTube 账号**（邮箱 + 密码，用来登录授权）+ 要绑到**哪个新闻频道 + 哪个语言**。

我拿到后：把 客户端 ID / 密钥 配进系统 → 我在面板上用你给的账号点「授权 YouTube」登录一下 → 绑定完成 → 以后自动发布。

# 常见问题

| 现象 | 怎么办 |
|---|---|
| 找不到「凭据 / Credentials」 | ☰ 菜单 → API 和服务 → 凭据 |
| 创建客户端 ID 时没有「重定向 URI」输入框 | 应用类型要选 **Web 应用（Web application）**，别选别的类型 |
| 授权时「未经验证的应用」拦截 | 正常现象（未做 Google 验证）→ 点「高级 / Advanced → 继续前往 xxx（不安全）」即可 |
| 授权时「已阻止访问」 | 应用还在「测试中」且该账号没加测试用户 → 要么发布应用(第5步)，要么把账号加进测试用户(第6步) |
| redirect_uri_mismatch | 第 4 大步的回调地址没填对/没保存 → 回去核对那一行，必须与文档完全一致 |

任何一步卡住，截图发我。谢谢！🙏
