## 先看懂：我们要干什么

我们的系统要**自动把做好的视频上传到 YouTube**。为此，系统需要得到某个 YouTube 账号的「上传授权」。
- **你的任务**：把 YouTube 账号准备好，并做一个 Google 后台的小设置（加“测试用户”），让我能顺利授权。
- **我的任务**：在系统里用你准备的账号登录、点同意，一次就绑定好。

整个配置，你这边大概 10 分钟。下面分 3 大步。

---

# 第 1 大步：准备好 YouTube 频道

**目的**：确保有一个能上传视频的 YouTube 频道，并且有一个 Google 账号能管理它。

1. 打开浏览器，访问 **https://www.youtube.com** ，用要发布的 Google 账号登录（右上角头像确认是这个账号）。
2. 点右上角头像 → 如果显示「创建频道 / Create a channel」，说明还没频道，点它，按提示创建一个频道（填频道名即可）。如果已经有频道，跳过。
3. 验证能上传：访问 **https://studio.youtube.com** 。
   - 能正常进入 YouTube Studio 后台、右上角有「创建 / CREATE」按钮，就说明这个账号能管理并上传视频。✅
4. 记下这个 **Google 账号邮箱**（后面要用）。

> 如果一个 Google 账号下有多个频道（品牌账号），确认你现在选的是**要用来发布的那个频道**。

---

# 第 2 大步：把这个 Google 账号加进系统的「测试用户」名单 ⚠️ 最关键

**为什么**：我们系统用的 Google 授权应用目前是「测试」状态。Google 规定——**只有被列进“测试用户”名单的账号，才能给这个应用授权**。不加的话，我在系统里授权时会被 Google 拦下，报「已阻止访问 / This app isn't verified / 应用未经验证」。

> ⚠️ 这一步必须在**拥有我们这个授权应用的 Google Cloud 项目**里操作。
> 如果你**没有**这个项目的访问权限，就跳过整个第 2 大步，直接把你的 Google 账号邮箱发给我，我来加。
> 如果你**有**权限（或由掌管这个项目的人操作），按下面做：

### 2.1 打开 Google Cloud 控制台
1. 访问 **https://console.cloud.google.com**
2. 用**拥有该项目的 Google 账号**登录（注意：这**不一定**是第 1 步那个发视频的账号，而是管理我们系统这个授权应用的账号）。

### 2.2 选中正确的项目
1. 看页面**最顶部**、Google Cloud 标志右边有一个**项目名称下拉框**，点它。
2. 弹出的窗口里，找到包含下面这个客户端 ID 的项目并选中：
   ```
   917092367693-n4rbj9bn90rfa13jl88co1gpl6ulvd0k.apps.googleusercontent.com
   ```
   （客户端 ID 的开头数字 **917092367693** 就是项目编号，认准它。）

### 2.3 进入「OAuth 同意屏幕 / 目标对象」页面
- 点左上角 **☰（三条横线菜单）→ API 和服务（APIs & Services）→ OAuth 同意屏幕（OAuth consent screen）**。
- 说明：Google 后台界面有新旧两版，你可能看到的是——
  - **旧版**：直接在「OAuth 同意屏幕」页面往下拉，能看到 **测试用户（Test users）** 区块。
  - **新版**：左侧菜单叫「**Google Auth Platform**」，里面有一项 **目标对象（Audience）**，点进去，往下找到 **测试用户（Test users）** 区块。

### 2.4 添加测试用户
1. 在「测试用户 / Test users」区块，点 **+ 添加用户（+ ADD USERS）**。
2. 在输入框里填入 **第 1 步那个发视频的 Google 账号邮箱**（完整邮箱，如 `xxxx@gmail.com`）。
3. 点 **保存（SAVE）**。
4. 保存后能在测试用户列表里看到这个邮箱，就成功了。✅（立即生效，不用等。）

> 如果有多个 YouTube 账号要接，把每个账号的邮箱都加进这个列表。

---

# 第 3 大步：确认「YouTube Data API」已开启

**目的**：确保这个项目允许调用 YouTube 上传接口。（通常早已开启，确认一下即可。）

1. 还在 Google Cloud 控制台、同一个项目里。
2. 点 **☰ 菜单 → API 和服务 → 已启用的 API 和服务（Enabled APIs & services）**。
3. 在列表里找 **YouTube Data API v3**。
   - **有** → 完成，什么都不用做。✅
   - **没有** → 点上方 **+ 启用 API 和服务（+ ENABLE APIS AND SERVICES）** → 搜索框输入 `YouTube Data API v3` → 点进去 → 点 **启用（ENABLE）**。

# 常见问题排查

| 现象 | 原因 / 怎么办 |
|---|---|
| 我授权时报「已阻止访问 / This app isn't verified / 应用未经验证」 | 第 2 大步没加测试用户，或加错了账号邮箱 → 回第 2 大步重新加对 |
| 报「redirect_uri_mismatch（重定向地址不匹配）」 | OAuth 客户端里没登记回调地址 → 按「固定信息」表把回调地址补登记进去 |
| 授权成功但系统提示「没拿到 refresh_token」 | 这个账号以前授权过 → 到 https://myaccount.google.com/permissions 找到并撤销该应用，我再重新授权 |
| 找不到「测试用户」在哪 | 新版 Google 后台在「Google Auth Platform → 目标对象(Audience)」里；旧版在「OAuth 同意屏幕」页面下方 |
